# Thread Scalability Analysis

Pesquisa experimental sobre o impacto da quantidade de threads,
da dimensão das matrizes e dos padrões de acesso à memória
no desempenho computacional da multiplicação de matrizes.

## Tecnologias

- Linguagem C
- OpenMP
- GCC
- Linux (WSL 2)
- Python
